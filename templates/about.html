About the project

Structured data,
without writing structure.

RichStruct is a schema generator and validator that turns Schema.org vocabulary into guided forms — so producing valid JSON-LD doesn't require knowing JSON-LD.

It exists because rich results shouldn't hinge on a missing comma.

The problem

Manual JSON-LD breaks quietly.

Writing structured data by hand means knowing Schema.org's vocabulary, which properties each type requires, and what Google's rich results actually expect. A wrong property name or a missing field doesn't throw an error — it just fails to appear in search results, with no clear signal why.

The approach

Forms first, JSON-LD second.

RichStruct generates the right input form for each schema type, marks what's required, and builds correctly nested, correctly typed markup automatically. Existing markup can be pasted in and checked through the same three-stage validator — syntax, Schema.org compliance, then rich-result eligibility.
